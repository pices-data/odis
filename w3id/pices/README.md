# w3id.org/pices

Persistent identifiers for the North Pacific Marine Science Organization
(PICES), https://meetings.pices.int/ (ROR: https://ror.org/0205jhq31).

| Path | Redirects to | Purpose |
| --- | --- | --- |
| `https://w3id.org/pices/odis/` | https://pices-data.github.io/odis/ (GitHub Pages of `pices-data/odis`) | schema.org JSON-LD descriptions of the PICES Data Catalogue and the sitemap harvested by the IOC Ocean Data and Information System (ODIS) |

Maintainers:

- Brett Johnson, PICES Technical Committee on Data Exchange (TCODE), WG-52 co-chair,
  GitHub `@Br-Johnson`, johnson@psc.org
- GitHub organisation `pices-data` (PICES data repositories)

The `odis/` subdirectory holds its own `.htaccess`; further PICES namespaces can
be added as sibling directories.
