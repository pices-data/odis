# w3id.org/pices/odis

Redirects every path under `https://w3id.org/pices/odis/` to the PICES ODIS
JSON-LD directory served by GitHub Pages from the public repository
`pices-data/odis` (https://pices-data.github.io/odis/). The directory holds one
schema.org JSON-LD file per record of the PICES Data Catalogue (Zenodo
community `pices`), a DataCatalog node, an Organization node and the
`sitemap.xml` registered in the ODIS Catalogue of Sources (ODISCat).
